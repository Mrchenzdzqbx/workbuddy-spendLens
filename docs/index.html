Local-first cost analytics

把 AI 账单
变成行动清单

读 WorkBuddy 的请求级日志，算清套餐成本、官方 API 等价、Token 构成与模型消耗。 不是再给你一张报表，而是告诉你下次该改哪个动作。

打开在线演示 → 分析我的日志

日志只在浏览器本地解析，不上传；正式版首次需手动授权日志目录。

界面来自脱敏演示数据，会话与文件名已中性化。 单文件 · 零依赖 · 可离线

不只看花了多少，还看为什么

成本、交付、模型与证据放在同一页，结论可以一路下钻复核。

01 / COST

四套成本口径分开算

套餐期间实付、官方 API 等价、WorkBuddy 省下和优化空间各自独立，不把事实与估算加在一起。

02 / ATTRIBUTION

从项目追到单个请求

按项目、会话、任务原型、模型和工具拆解，再用账本明细回到原始证据，避免只看总数。

03 / ACTION

建议带门槛与边界

模型下沉要求足够的同任务样本；优势不足就保持现状。所有估算都标注口径和已知误差。

三步开始

  1. 先看演示：无需日志，打开即可浏览 7 个页签。
  2. 再看自己的账单：正式版选择或拖入 ~/.workbuddy/projects。
  3. 从一条动作开始：先做证据最充分、改动最小的建议。
